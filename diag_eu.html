Notice rapide d'utilisation
1

Récupérer le SN ou le DID du robot

  • Carte mère d'origine : le numéro de série (SN) est sur l'étiquette QR code sous le couvercle du robot.
  • Carte mère remplacée : l'étiquette ne correspond plus — il faut lire le SN ou le DID dans le menu caché de l'application Dreamehome :
  1. Le client ouvre l'application et entre dans son robot, puis appuie sur le menu ⋮ (en haut à droite).
  2. Appuyer sur « Historique de nettoyage ».
  3. Appuyer 10 fois sur le compteur en haut (zone totale / durée / cycles), même s'il est vide.
  4. L'écran network information s'ouvre : relever la ligne did ou sn.
2

Se connecter et saisir le SN ou le DID

  1. Cliquer sur Ouvrir l'outil de diagnostic ci-dessus et se connecter avec le compte et le mot de passe.
  2. Au besoin, passer l'interface en français avec le bouton de langue en haut à droite (中 → Français).
  3. Dans Diagnostic des pannes, choisir l'onglet SN ou DID selon le numéro relevé.
  4. Coller le numéro puis cliquer sur Query / Rechercher.
L'onglet Code d'autorisation (Auth) et l'Assistant de port série FCT ne servent pas pour cette consultation.
3

Lire les anomalies en mémoire

Le bloc Informations sur l'erreur liste chaque anomalie enregistrée par le robot :

Type d'anomalieLibellé du problème (ex. capteur laser obstrué, serpillière tombée…)
CatégorieImportant = défaut à traiter · Scénario = événement d'utilisation
Code d'erreurNuméro du code (à croiser avec les codes erreur du hub)
Première / Dernière foisDate et heure de la 1re et de la dernière apparition
NombreNombre d'occurrences — un défaut répété est plus significatif qu'un événement isolé
Première / Dernière ver.Version firmware lors de la 1re et de la dernière apparition
Exemple : erreur 48 le 19/09/2026 — vérifier si le capteur de distance laser est obstrué (1 fois) ; erreur 69 le 05/08/2026 — la serpillière est tombée (1 fois).
Les heures sont affichées sur le fuseau choisi en haut à droite (par défaut UTC+8 Pékin, soit +6 h par rapport à l'heure de Paris en été). Le bloc Motif probable de recours au SAV propose une cause quand l'outil en trouve une ; Actualiser recharge les données du robot.
Source : SOP of After-Sale Diagnosis Tool — Dreame Technical Support Team, 31/07/2026
