🔗 Paramètres de la source — lien Google Sheets, BOM mémorisées, clé API
Collez le lien du fichier BOM partagé sur Google Drive : les données sont lues directement en ligne, sans téléchargement ni import manuel.
⚙ Option : clé API Google — version complète en consultation directe (photos, feuilles, références barrées)
À créer une seule fois : console.cloud.google.com → créer un projet → « API et services » → activer Google Drive API et Google Sheets API → « Identifiants » → « Créer des identifiants » → Clé API. Par sécurité, restreignez la clé à ces deux APIs uniquement. Elle est enregistrée uniquement dans le navigateur de ce poste et ne donne accès qu'aux documents déjà partagés par lien.
—
ℹ️ Le document Google Sheets doit être partagé en « Tous les utilisateurs disposant du lien » (rôle Lecteur). Sinon, Google bloque la lecture directe — utilisez alors l'onglet Téléchargement / Importation.
