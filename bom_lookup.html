🔄 Mettre à jour depuis le Google Sheet

Les données affichées proviennent du fichier data/bom_lookup.json, généré à partir du Google Sheet BOM Quick Lookup de Dreame. L'export « page web » est utilisé (et non le .xlsx) car il conserve tous les liens d'une cellule.

Procédure :
  1. Ouvrir le Google Sheet source
  2. Menu Fichier → Télécharger → Page web (.html, zip)
  3. Déposer le .zip ci-dessous : l'aperçu se met à jour immédiatement
  4. Cliquer Télécharger bom_lookup.json et remplacer dreame_sav/data/bom_lookup.json, puis publier (push GitHub)
